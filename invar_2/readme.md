# Скрипт для тихой установки ПО для компьютерных аудиторий.

## Список устанавливаемого ПО

Основной список (все аудитории)
- Инструменты разработки: Git, GitHub Desktop, Visual Studio Code, Docker Desktop, PyCharm Community Edition, Python, Julia, Rust, MSYS2.
- Научное и аналитическое ПО: Maxima, KNIME Analytics Platform, Anaconda.
- Офисное и вспомогательное: GIMP, Zettlr, MiKTeX, TeXstudio, Far Manager, SumatraPDF, Flameshot, Qalculate!, 7Zip.
- Браузеры: Google Chrome, Mozilla Firefox, Microsoft Edge, Arc, Yandex Browser.
- Коммуникации: Yandex Telemost (через MSI), Sber Jazz.
- Среды: WSL 2 с Ubuntu 22.04 и Ubuntu 24.04.
- Расширения VS Code: Python, Pylance, C/C++, Docker, HTML/CSS, ESLint, Prettier, Live Server, GitLens, GitHub PR, Julia, Rust Analyzer, LaTeX Workshop, Remote-WSL, Code Spell Checker, Markdown All in One, YAML.

Дополнительный список (аудитория 313)
- Ramus Educational
- ARIS EXPRESS
- Archi

## Использование

- Скопировать скрипты
- Запустить `install.bat`
- Выбрать, нужно ли устанавливать ПО из дополнительного списка (Y/N)
- По завершении перезагрузить помпьютер
